# PLAN.md — «Factory Defense» (tower defense × factory)

> **Статус документа: ранний концепт, не статус релиза и не точный чек-лист текущих возможностей.** Код и дизайн уже разошлись с этим черновиком; актуальное направление после обсуждения записано в `ROADMAP.md`.
> Сборка проекта: `python3 tools/build.py` → автономный `dist/factory-defense.html`; проверка: `node tools/smoke.js`. Игровое поле сейчас рисуется на canvas, интерфейс — HTML/CSS.

---

## 1. Концепция

**Жанр:** tower defense с производственной цепочкой (Factorio × TD).
**Питч:** враги идут к твоему ядру. Турели без патронов — просто железо. Ты строишь шахты → конвейеры → плавильни → патронные цеха → депо снабжения, и только потом — линию обороны. Фабрика — это вторая половина игры, а не меню апгрейдов.

**Кор-цикл:**
```
Добыча руды → Конвейеры → Переработка → Боеприпасы/энергия → Депо снабжения
     ↓                                                          ↓
  Строим/расширяем  ←  Волна врагов  ←  Отбиваемся  ←  Турели в радиусе депо
```

**Фантазия игрока:** «сначала выжить, потом построить конвейер мечты, который сам кормит линию турелей».

## 2. Принятые решения (зафиксировано)

| Параметр | Решение |
|---|---|
| Основной цикл | Конвейеры, ресурсы, фабрики снабжают турели |
| Стек | HTML + CSS + JavaScript |
| Финальный артефакт | Один самодостаточный `.html` (всё инлайн, офлайн, без внешних запросов) |
| Стиль | Пиксель-арт, сетка 16×16, `image-rendering: pixelated` |
| Масштаб v1 | Полный: карты, дерево прокачки, сейвы, боссы, звук |
| Рендеринг | DOM + CSS (тайлы — сетка, сущности — `transform`). **План B:** canvas-слой, если DOM не тянет 60 FPS |
| Логика | JS, фиксированный шаг симуляции 60 Гц + `requestAnimationFrame` |

## 3. Игровые системы

### 3.1. Карта и сетка
- Тайловая сетка **48×32 тайла** (тайл 20 px, карта 960×640, масштабируется CSS-трансформом под экран).
- Типы тайлов: земля, рудные жилы (4 типа), скалы (нельзя строить), вода (нельзя строить), стартовая площадка.
- **Ядро (Core):** здание игрока, HP ~1000. Проигрыш = HP 0.
- **Постройка:** курсор-призрак валидного/невалидного тайла, ЛКМ — поставить, ПКМ — снести (возврат 70%).

### 3.2. Движение врагов (решение)
- **A\* по тайлам** с пересчётом маршрута при изменении застройки (пересчёт локальный, дешёвый).
- Все постройки блокируют путь. **Валидация размещения не даёт замкнуть путь полностью** (если после постройки ядро недостижимо — отмена с подсказкой «Путь перекрыт»).
- Летающие враги идут **напрямую по воздуху** (игнорируют лабиринт), их бьют только турели с флагом `anti-air`.

### 3.3. Ресурсы (4 вида)
| Ресурс | Добыча | Использование |
|---|---|---|
| 🟤 Железо | железная жила | ленты, базовые патроны, броня ядра |
| 🟠 Медь | медная жила | электроника, лазер, тесла, провода |
| ⚫ Уголь | угольная жила | топливо плавильни/станции, ракеты |
| 🔷 Кристалл | кристальная жила | ракеты, продвинутые исследования |

Предметы — **отдельные сущности на ленте** (видимые коробочки), лимит ~400 предметов на карте (пул объектов).

### 3.4. Производственная цепочка
```
Шахта (стоит на жиле) → [руда] → Конвейер → Плавильня → [слиток] → Патронный цех → [патроны]
                                                       ↘ Электростанция (уголь) → [энергия]
Забор/сплиттер: ветвление и объединение лент. Склад: буфер, если цех не успевает.
```
- **Конвейер:** 1 тайл/тик-движения (скорость — апгрейд), направление поворотом при постройке, сплиттер — 1 в 2.
- **Цеха:** рецепт + время крафта (например, 2 железа → 5 патронов за 2 сек).
- **Энергия как предмет** (батарейки), не глобальная сеть — проще и нагляднее.

### 3.5. Снабжение турелей (решение)
- **Депо снабжения (Ammo Depot):** принимает патроны/батарейки с ленты, имеет радиус ~6 тайлов.
- Турели в радиусе **автоматически** получают боезапас. Вне радиуса — не стреляют (индикатор «нет снабжения»).
- Это убирает необходимость тянуть ленту к каждой турели, сохраняя всю магию логистики.

### 3.6. Турели (6 шт.)
| # | Название | Стреляет | Особенность |
|---|---|---|---|
| 1 | Пулемётная | патроны | быстрая, дешёвая, базовая |
| 2 | Пушка | бронебойные | сплеш, медленная, против брони |
| 3 | Лазерная | батарейки | точный луч, игнорирует 50% брони |
| 4 | Тесла | батарейки | цепной урон 3 цели, малый радиус |
| 5 | Ракетная | ракеты | большая дальность, самонаведение, не бьёт вблизи |
| 6 | Зенитная | зенитные патроны | только anti-air, очень быстро |

У каждой турели: **3 уровня апгрейда** (урон / скорострельность / радиус), видимые изменения спрайта (флаги, ствол, размер).

### 3.7. Враги (7 типов + боссы)
| Тип | Роль |
|---|---|
| Бегун | быстрый, мало HP |
| Солдат | стандартный |
| Броневик | высокая броня, медленный |
| Летун | летает напрямую к ядру |
| Сплиттер | при смерти делится на 2–3 мелких |
| Ремонтник | лечит врагов вокруг |
| Сапёр | **атакует постройки** (грызёт стены/турели) |
| **Боссы** | Титан (HP), Щитовой (энергощит), Рой (спавнит бегунов) — каждая 10-я волна |

### 3.8. Волны
- **30 волн**, состав — смесь скриптованного и процедурного (масштаб HP/скорости по номеру волны).
- Между волнами — **фаза подготовки** (таймер, кнопка «Начать волну сейчас» → бонус ресурсов).
- Прогресс-бар волны, счётчик оставшихся врагов.

### 3.9. Прогрессия (дерево исследований)
- **Лаборатория** крафтит 🔬 нау-пакеты (из слитков + кристаллов).
- 4 ветки по 4–5 узлов:
  - **Оружие:** урон, бронебойность, сплеш
  - **Логистика:** скорость лент, радиус депо, вместимость складов
  - **Производство:** скорость цехов, экономия руды, доп. жилы (шахта +20%)
  - **Оборона:** HP ядра, ремонт, сопротивление
- Узлы покупаются за нау-пакеты, эффекты — мультипликаторы в `config.js`.

### 3.10. Экономика
- Старт: немного железа/меди + ядро.
- Доход: добыча (единственный источник) + бонусы за досрочный старт волны.
- Продажа построек — 70% стоимости. Ремонт ядра — за железо.

## 4. Визуал и звук

**Пиксель-арт:**
- Спрайты 16×16 (тайлы, постройки) и 12×12/16×16 (враги), палитра ~24 цвета.
- Источник спрайтов: скрипт `tools/sprites.py` (Pillow) рисует их **пиксель-матрицами из кода** → PNG → base64 **data-URI**, встроенные в сборку. Никаких внешних файлов.
- Анимация: 2–4 кадра на постройку/врага (CSS `steps()` или смена background-position).
- Шрифт UI: моноширинный, «пиксельный» вид (встроенный битмап-шрифт subset base64 или системный monospace с жёсткими тенями).
- Эффекты: вспышки выстрелов, дым при уничтожении, полоски HP, «+5» при добыче — CSS-анимации.

**Звук (WebAudio, синтез — ноль файлов):**
- Выстрелы (шум+осциллятор), взрывы, клики UI, сигнал волны, «нет патронов».
- Опционально: простой чиптюн-луп (sequencer из осцилляторов), выключается в настройках.

**Принципы:**
- Вся балансировка — только в `config.js` (никаких «магических чисел» в логике).
- Сущности живут в `state`, рендер — чистая проекция (можно будет переписать рендер на canvas без правки логики).
- Объектные пулы для врагов, пуль, предметов (без GC-фризов).

## 6. Standalone-сборка

`tools/build.py`:
1. Читает `index.html`, инлайнит `<link>` → `<style>`, `<script src>` → `<script>`.
2. Встраивает data-URI спрайты из `sprites.py`.
3. Проверяет: **ноль внешних запросов** (нет http://, //, url(внешний)).
4. Пишет `dist/factory-defense.html` — один файл, работает офлайн по двойному клику.
- Сейвы продолжают работать: `localStorage` в file:// режиме доступен.

## 7. Управление и UI

**Ввод:** мышь + клавиатура; тач-базовый (крупные кнопки, работает и на планшете).
- ЛКМ — поставить/выбрать, ПКМ — снести/отмена, ПКМ-перетаскивание — протяжка ленты.
- `1–6` — быстрый выбор турели, `Q/W/E/R` — меню (постройки/логистика/исследования/снос), `Space` — пауза, `F` — начать волну, `Tab` — скорость (1×/2×/3×).

**Экраны:** главное меню → выбор карты → бой → победа/поражение (со статистикой).
**HUD:** ресурсы (4 иконки), HP ядра, номер волны + таймер, скорость, пауза.
**Панели:** магазин построек (категории), инфо-панель выбранного (апгрейд, продать), дерево исследований, настройки.

## 9. Вехи (Milestones) и критерии готовности

| # | Веха | Критерий «готово» |
|---|---|---|
| **M0** | Каркас | Сетка, рендер карты, игровой цикл, пауза/скорость, спрайты-заглушки |
| **M1** | Ядро TD | Ядро, A*-враги, 2 турели (беспатронные), волны, HP, проигрыш/победа волны |
| **M2** | Фабрика | Шахты, ленты, предметы, плавильня, патронный цех, депо, турели едят патроны |
| **M3** | Бой | 6 турелей, 7 врагов, боссы, сплиттер/сапёр/летун, снабжение-индикаторы |
| **M4** | Прогрессия | 5 карт, дерево исследований, лаборатория, апгрейды турелей, экраны меню |
| **M5** | Полировка | Сейвы (3 слота + автосейв), звук, баланс 30 волн, эффекты, статистика |

## 10. Риски и как их гасим

| Риск | Митигация |
|---|---|
| DOM-рендер не тянет много сущностей | Пулы + `transform` (не `top/left`); при провале — canvas-слой поверх той же модели (архитектура уже разделена) |
| A* дорогой при перестройке | Пересчёт только при изменении карты + кэш путей; враги не пересчитывают каждый тик |
| Баланс «слишком сложно объять» | Всё в `config.js`; каждая веха — играбельный билд, балансируем итеративно |
| Один HTML раздувается | Спрайты — компактные палитровые PNG (16×16, ~100–300 байт), шрифт subset; цель < 1.5 МБ |
| Сложность логистики отпугивает | Туториал-волны 1–3 с подсказками; депо снабжения упрощает подвод патронов |
