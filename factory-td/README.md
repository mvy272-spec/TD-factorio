# Factory Defense

Пиксельная tower defense × factory игра: конвейеры, ресурсы, фабрики, турели, 30 волн, боссы.

> Сейчас это развиваемый прототип, а не готовый релиз. Актуальное направление и этапы: [`ROADMAP.md`](ROADMAP.md); технический handoff: [`HANDOFF.md`](HANDOFF.md). Исходный архив сохранён в корне Git-репозитория.

## Как играть

**Готовый файл:** открой `dist/factory-defense.html` в любом браузере (работает офлайн, всё в одном файле).

**Разработка:** `index.html` + `js/` + `css/`.

## Цикл игры

```
Шахта (на руде) → Конвейер → Плавильня → Слитки → Цеха → Боеприпасы
                                                        ↓
Слитки/уголь/кристаллы/нау/еда → в ЯДРО (склад)   Депо снабжения → Турели
```

- Ядро принимает: железо, медь, уголь, кристаллы, нау-пакеты, **еду** (и руду 2:1 в слиток).
- Турели без патронов не стреляют. Депо раздаёт боеприпасы всем турелям в радиусе.
- Полностью перекрыть путь врагов к ядру нельзя.
- Каждая 10-я волна — босс. 30 волн → победа → бесконечный режим.

## 👷 Население и рабочие

- **Жилые дома** (🏘 категория «Город») дают +8 рабочих.
- **Фермы** производят **еду** — вези её конвейером в ядро, население ест автоматически. Без еды — 🍞 голод и −45% скорости производства.
- Шахты, фермы и цеха требуют рабочих (иконка 👷N в меню построек). Занятость в HUD: ниже 100% — стройте дома, выше — бонус до 115%.
- **Оружейная** даёт +15% урона турелям в радиусе (максимум 2 на турель).

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | поставить / выбрать |
| **ЛКМ + протяжка** | **провести линию конвейеров — направление и повороты автоматические** |
| ПКМ | снести (возврат 70%) / отмена режима |
| **ПКМ + протяжка** | **снести линию лент** |
| R | повернуть (ленты, шахты, турели) |
| F | вызвать волну досрочно (+ресурсы) |
| Space / Esc | пауза |
| 1 / 2 / 3 | скорость времени |
| X | продать выбранное |
| Q W E I | шахта, лента, сплиттер, контейнер |
| S A H B M L | плавильня, патронный, снарядный, аккум., ракетный, лаборатория |
| V G C N Y K Z | стена, пулемёт, пушка, лазер, тесла, ракетная, зенитная |
| O P J | жилой дом, ферма, оружейная |

Хоткеи работают и на **русской раскладке** (привязаны к физическим клавишам).

**Визуальные подсказки:** красный «!» на ленте — тупик; жёлтая метка — пробка; красный пунктир — маршрут врагов; жёлтое кольцо — цель текущего квеста обучения; красная вуаль — голод населения.

## Сборка standalone

```bash
python3 tools/build.py     # → dist/factory-defense.html (всё инлайн, 0 внешних запросов)
```

## Тесты

```bash
node tools/smoke.js        # headless-прогон симуляции: карта, фабрика, бой, сейвы, волны
```

## Структура

- `js/config.js` — вся балансировка (цены, урон, волны, исследования, карты)
- `js/sim.js` — симуляция: A*, ленты, фабрики, турели, враги, волны, сейвы
- `js/render.js` — canvas-рендер поля
- `js/ui.js` — HUD, панели, модалки, сохранения
- `js/sprites.js` — процедурные пиксель-спрайты
- `js/audio.js` — WebAudio-синтез звуков и музыки
