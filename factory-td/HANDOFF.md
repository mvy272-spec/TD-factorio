# Handoff для следующего разработчика / ИИ

## Контекст продукта

Factory Defense — бесплатная браузерная игра для ПК: примерно 50/50 tower defense и factory/logistics. Цели: напряжённая оборона, свободное и понятное строительство, заметный прогресс, улучшенный визуал и звук. Русский язык — сначала, английский — позднее. Пользователь хочет автономный single-file HTML для демонстрации на itch.io/в сообществе.

Подробная согласованная цель и этапы находятся в [`ROADMAP.md`](ROADMAP.md). Не считать старый [`PLAN.md`](PLAN.md) достоверным описанием текущей реализации: он сохранён как ранний концепт.

## Структура

- Репозиторий больше не состоит только из архива: исходники распакованы в `factory-td/`.
- Оригинальный `factory-td.rar` сохранён в корне репозитория как исходная копия.
- `assets/title-background.jpg` — сгенерированная для игры пиксельная иллюстрация главного меню; она уже подключена к интерфейсу.
- `dist/` игнорируется Git. Автономный HTML создаётся сборкой и предназначен для проверки/публикации как release asset.

## Сборка и проверки

Из каталога `factory-td/`:

```bash
node tools/smoke.js
python3 tools/build.py
```

Сборка создаёт `factory-td/dist/factory-defense.html`. Локальные CSS-изображения встраиваются как data URI; внешних запросов быть не должно. На момент handoff smoke-тесты и сборка проходят. Полноценного браузерного/ручного плейтеста ещё не было.

## Что уже сделано

- Исправлена проверка размещения: здание, закрывающее последний проход к ядру, теперь отклоняется. Добавлен regression test.
- Сейвы восстанавливают активную волну, очередь спавна, врагов и снаряды; сохранены проверки этого поведения.
- Туториал начинает с постановки первой турели, затем ведёт в добычу и снабжение.
- Сплиттер визуально отличим от ленты; повтор прохождения сохраняет выбранную сложность.
- Добавлены иллюстрация меню и автономное встраивание локальных CSS-ресурсов.
- `ROADMAP.md` отражает ответы автора и разделяет цель релиза и дальнейшие этапы.

## Что ещё не реализовано

Кампания и сюжет, конечные месторождения, дополнительные ресурсы, энергосеть, многопредметные/модернизируемые ленты, размеры заводов и порты, поздние дроны/поезда, глубокая специализация турелей, новые боссы и крупная переработка внутриигровых моделей/анимаций. Следовать приоритетам из `ROADMAP.md`, не выдавать эти пункты за готовые функции.

Можно сверять UX/читаемость с Mindustry, Factorio и другими стратегиями, а для оригинальных ассетов пользоваться генерацией изображений в чате. Сохранять целостный пиксельный стиль. Итоговые файлы держать в `assets/` и встраивать в standalone-сборку, а не загружать во время игры.
